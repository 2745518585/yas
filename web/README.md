# YAS 网页连接包

1. 解压整个 ZIP，运行「安装网页连接.cmd」，允许 Windows 管理员权限提示。
2. 打开原神的圣遗物背包，并拉到顶部。
3. 在圣遗物网页点击「启动并连接 YAS」，允许浏览器打开应用和访问本机网络。
4. 在 YAS 弹窗中检查网站地址，授权后选择游戏窗口，开始扫描。

扫描日志显示在网页，成功后自动导入。网页取消、鼠标右键中断、识别失败、翻页错误或空结果均不会自动导入。关闭 YAS 服务窗口也会结束正在进行的扫描。网页失联超过两分钟会自动停止扫描，单次扫描最长三十分钟。服务空闲十五分钟后退出，下次从网页唤起即可。

安装会复制程序到 `%LOCALAPPDATA%\YAS\Web` 并注册当前用户的 `yas-scan://` 唤起协议，不需要保留解压目录。更新时先关闭正在运行的 YAS 服务，再从新连接包运行安装脚本。运行「卸载网页连接.cmd」可移除协议；关闭服务后可以手动删除安装目录。

也可以直接以管理员身份运行 `yas_artifact.exe --serve`，然后在网页点击「连接已运行的 YAS」。普通命令行扫描保持可用，不使用网页也可直接运行程序并手动导入 `mona.json`。

服务只监听 `127.0.0.1:32334`，不会向其他电脑提供访问。网站授权按来源与临时令牌绑定，仅能传入圣遗物扫描选项，不能执行任意程序。无需椰羊辅助插件、远程签名或自动更新服务。
